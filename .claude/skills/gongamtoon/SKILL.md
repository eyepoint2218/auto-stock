# 오누이 공감툰 (월·수·금 21:00, 한 장)

이 환경에서는 그림을 직접 만들 수 없다. **그림과 그림 속 글귀는 사용자가 ChatGPT로 만든다.**
이 스킬은 주제 선정 → 글귀 → 프롬프트 → 게시글 → 그림 확인 → 예약을 맡는다.

```
주제 → [1단계] 글귀 + 프롬프트 + post.yml 초안 → (사용자: ChatGPT로 그림 1장) → [2단계] 그림 확인 → [3단계] 예약
```

반드시 먼저 읽는다: `docs/gongam_guide.md` (캐릭터 고정·프롬프트 틀·글 규칙). 이 지침이 이 스킬보다 우선한다.

## 0. 원칙
- **기준 이미지(2026-11-24 교체)**: `assets/brand/onibomi_character.png`(캐릭터 시트) + `assets/brand/onibomi_wardrobe.png`(옷장 01~43번). 그림 프롬프트는 `docs/gongam_universal_prompt.md` 를 쓰고 `[장면]` 대신 `[옷]`·`[분위기]`를 채운다. 예전 `siblings_*` 파일은 삭제됨.
- **GPT는 글자 없는 그림만** (2026-11-24 변경): 글귀는 post.yml `copy:` 에 적고, 글귀는 프로그램이 넣는다 (채널명은 넣지 않음, 운영자가 직접)(Pretendard Medium, 세로 2.0%, 위에서 19%, 옅은 번짐). 프롬프트에 [글귀]·[채널명] 블록을 넣지 않는다. 그림을 받으면 글자가 없는지, 위쪽 글귀 자리가 차분한지 확인하고 `preview` 로 최종본을 만든다.
- **옷에 로고·글씨 없음**: 패딩 포함 모든 옷·신발·가방은 민무늬. 그림에 로고·글씨가 보이면 지워 달라고 한다.
- **한강 배경 금지**: 한강·강변 둔치·한강 다리·강 건너 야경을 장면에 쓰지 않는다.
- **하단 채널명 자리 비움**: 맨 아래 88~95% 가운데 40% 폭은 바닥처럼 단순하게 비운다 (운영자가 '온이봄이 @onibomi.toon' 직접 넣음, 프로그램은 넣지 않음).
- **배경 단순하게**: 하늘·땅·길 같은 큰 면 위주, 배경 요소 2~3개만. 그림 확인 때 배경이 복잡하면 "캐릭터는 그대로 두고 배경의 사람·차·간판·잔가지를 빼서 단순하게"를 요청하게 한다.
- **초광각 렌즈 뷰**: 14~16mm 초광각, 낮은 눈높이, 강한 원근의 넓은 풍경.
- **캐릭터 작게 풍경 많이**: 두 사람 높이 화면 세로의 15~20%, 화면 아래쪽 1/4 안, 80% 이상 풍경 (기준 `assets/brand/onibomi_mood_ref.jpg`).
- **어린이 책가방 금지**: 시트의 노란·분홍 책가방은 쓰지 않는다. 장면에 가방이 필요할 때만 심플한 백팩(오빠 짙은 남색, 동생 크림색, 무늬·글자 없음), 필요 없으면 가방 없이. 프롬프트 `[캐릭터 고정]` 의 '가방' 줄을 그대로 쓴다.
- **운영자가 직접 준 문장은 즉시 게시**: 원문 그대로 프롬프트를 바로 만들고, 계획표 날짜에 끼워 넣지 않는다. 그림이 오면 바로 확정본(1440×1800 PNG + 게시글)을 만들어 지금 올리게 한다. 운영자가 "예약"이라고 할 때만 `next-slot` 빈자리에 넣는다.
- **의상 버전**: 회차마다 `docs/gongam_guide.md` '의상 버전 3가지' 중 하나를 고른다. 실내=기본, 12~2월 실외=패딩(두 번째 첨부 `siblings_winter.png`), 12/23·12/25=크리스마스(두 번째 첨부 `siblings_christmas.png`). 프롬프트 `[캐릭터 고정]` 오빠·동생 줄을 그 버전 블록으로 바꾼다.
- **정해진 스케줄대로**: "다음 회차"는 `data/gongam_topics.md` 계획표의 다음 `[ ]` 칸(날짜·40선 문장·장면)을 그대로 쓴다. 추가 문구(N번)는 사용자가 요청할 때만.
- **문장은 사용자가 준 40선과 `data/gongam_topics.md` '추가 문구(N번)'만 쓴다** (그림 글귀·게시글 모두). 게시글은 그 회차 문장 + 요일별 CTA 한 줄뿐, 설명 문장을 지어 넣지 않는다.
- **글귀 크기·위치·폰트는 고정** (`docs/gongam_guide.md` '글귀 고정값': 세로 2.0%, 위에서 19%, 가운데, 흰색 고딕체). 매 회차 `[글귀]` 블록은 지침 틀 그대로 복사하고 문구만 바꾼다.
- `channel: gongam` 을 꼭 적는다 (업로드 계정·해시태그·채널 소개가 이 채널 것으로 바뀜).
- 캐릭터 설명은 `docs/gongam_guide.md` 의 `[캐릭터 고정]` 블록을 **한 글자도 바꾸지 않고** 쓴다. 장면에 맞춰 옷을 바꿔도 오빠=빨강 상의, 동생=노랑 상의.
- 이모지 금지 (그림 글귀·게시글 모두). 인사로 시작 금지. CTA 하나.
- 실존 인물·브랜드 로고·간판은 넣지 않는다. 다른 계정의 캐릭터·글귀를 베끼지 않는다.
- 초안은 `drafts/gongam_<영문슬러그>/` 에 `draft: true`. `queue/` 에는 그림이 확인된 뒤에만 옮긴다.

## 1단계. 주제 → 글귀·프롬프트

1. **날짜 정하기**: `python -m screendaily next-slot --channel gongam --count 3` 으로 다음 빈자리를 본다. 그 요일이 결을 정한다 (월 위로·쉼 / 수 일상의 작은 위안 / 금 곁에 있는 사람). 모두 **감성 문구**, 웃음·말장난은 쓰지 않는다.
2. **주제**: 사용자가 주제를 주면 그걸로, "다음 거"면 `data/gongam_topics.md` 계획표의 다음 `[ ]` 칸을 쓴다. 계절·날씨·기념일(첫눈, 수능, 크리스마스, 새해)을 우선한다. `queue/` 에서 최근 gongam 게시물 2개와 장소·날씨·관계가 겹치지 않게 한다.
3. **글귀**: `data/gongam_topics.md` 연재 계획표에서 그 날짜의 문구·장면을 그대로 쓴다 (감성·위로 문구 40선, **원문 그대로**, 줄바꿈은 표의 `/` 위치). 날씨·계절이 안 맞으면 같은 요일의 안 쓴 문구와 바꾸고 표의 날짜도 고친다. 40선을 다 쓰면 사용자에게 새 문구를 받는다 (임의로 지어내지 않음).
4. **프롬프트**: `docs/gongam_guide.md` 2장의 틀을 통째로 쓰고 (글귀는 **기준 이미지와 같은 폰트·위치, 크기는 20% 작게**: 글자 높이 세로 2.0%, 위에서 19%, 가운데) `[장면]`(4문장), `[글귀]` 두 줄만 채운다. 장면은 실사 한국 일상 장소 + 시간대·날씨·빛 + 두 캐릭터의 관계가 보이는 자세 + 시트에 있는 표정. **원근감 필수**: 멀어지는 길·줄지은 사물로 소실점, 앞쪽 흐린 소품, 비스듬한 구도, 발밑 그림자를 장면 문장에 넣는다 ([규칙]의 원근감 4줄은 틀에 이미 있음).
5. **결과물**
   - `drafts/gongam_<slug>/post.yml` (아래 템플릿)
   - `drafts/gongam_<slug>/PROMPT.md`: 글귀(40선 번호)·프롬프트 전문·확인 체크리스트(지침 3장)
   - `data/gongam_topics.md` 계획표 상태를 `[x] 프롬프트 준비` → 예약하면 `[x] 예약` 으로 바꾼다
   - 채팅에는 **프롬프트 전문을 코드 블록 하나로** 바로 붙여 주고, 첨부할 파일 두 개를 순서대로(① `assets/brand/siblings_style_ref.jpg` 캐릭터·선 굵기·글귀 기준 ② `assets/brand/siblings_character.png` 각도·표정)를 알려 준 뒤 "그림을 올려 주세요" 한 줄로 끝낸다.

```yaml
# 오누이 공감툰: <주제> (그림·글귀: ChatGPT, docs/gongam_guide.md)
publish_at: "YYYY-MM-DD 21:00"
format: carousel
draft: true
channel: gongam
images: [img/post.jpg]
caption: |
  <글귀 첫째 줄>
  <글귀 둘째 줄>

  <요일별 CTA 하나: 월 저장 / 수 댓글(질문) / 금 공유, 감성 톤>
hashtags: [<장면 키워드 1~2개>]
```

## 2단계. 그림 받기 → 확인
1. 그림을 `drafts/gongam_<slug>/img/post.jpg` 로 저장 (PIL RGB 변환, quality 92).
2. **그림을 직접 보고** 지침 3장 체크리스트를 하나씩 확인한다. 특히:
   - 캐릭터: 오빠 더벅머리·빨강 상의 / 동생 일자 앞머리·노란 머리핀·노랑 상의 / 세로 타원 눈 / 빗금 볼터치 / 2D 유지
   - 글귀: 맞춤법·띄어쓰기가 요청과 **글자 단위로** 같은지, 다른 글자가 없는지
   - 글귀 크기·위치: `python -m screendaily textcheck img/post.jpg` → '다시'가 나오면 지침 3장 6번 문구로 글귀만 고쳐 달라고 한다
   - 우산 그림(`assets/brand/siblings_style_ref.jpg`)과 나란히 놓고 얼굴·**선 굵기·선 색**·채색을 비교한다 (시트는 각도·표정 확인용)
   틀린 곳이 있으면 지침 3장의 고침 문구를 그 내용에 맞춰 완성해서 주고 다시 받는다.
3. 미리보기: `python -m screendaily preview --drafts gongam_<slug> --force` → `out/01.jpg` 를 보고 4:5 로 잘리면서 글귀·얼굴이 잘리지 않았는지 확인. 잘리면 `cover_focus: "0.5,0.4"` 처럼 세로 위치를 조정한다.
4. `out/01.jpg` 를 `SendUserFile` 로 보여주고 `out/caption.txt` 의 게시글 전문도 채팅에 붙인다.

## 3단계. 예약 (그림 확인 후, 사용자가 원하면)
1. `next-slot` 으로 받은 시간(또는 사용자가 정한 월·수·금)으로 `queue/<YYYY-MM-DD>_2100/` 에 `post.yml` + `img/post.jpg` 를 복사하고, `draft: true` 를 지운다.
2. `python -m screendaily lint <폴더>` → 연재일·시간·이모지 경고가 없어야 한다.
3. 자동 업로드는 **main 의 `queue/`만** 본다. 사용자가 원하면 main 반영(PR 또는 지시에 따라)까지 진행한다.
4. 계정 연결 확인: GitHub Secrets 에 `IG_ACCESS_TOKEN_GONGAM`(+`IG_USER_ID_GONGAM`, 통합 로그인이면 Variables `IG_API_HOST_GONGAM`)이 없으면 업로드가 실패한다고 알려 준다. `config.yml` 의 `channels.gongam.handle` 이 `@gongam_todo` 면 실제 아이디로 바꾸자고 한다.
5. 미리 여러 편 쌓기: 사용자가 한 번에 여러 장을 주면 `next-slot --count N` 순서대로 배치한다 (월·수·금 결이 맞는 그림을 그 요일에).

## 게시물 구성
- 프로그램이 자동으로 **그림 한 장, 1440×1800**을 만든다. 하단 채널명은 GPT가 그림 안에 넣는다(프롬프트 `[채널명]`), 2단계에서 철자를 확인한다. 소개·팔로우 카드는 붙이지 않는다. `out/` 에 JPG·PNG.

## 만능 프롬프트
- 사용자가 '만능 프롬프트'를 원하거나 사진+분위기만 줄 때는 `docs/gongam_universal_prompt.md` 를 그대로 주고, [분위기] 줄만 채워 준다. 그림이 오면 글귀(copy)를 넣어 최종본을 만든다.

## 그림 받으면 자동 확인 (매번)
1. 옷·신발·가방·배경 간판에 로고·글씨가 있는지 확대해서 본다. 있으면 최종본을 만들지 말고 "그림은 그대로 두고 옷·신발·가방의 로고와 글씨만 모두 지워서 민무늬로" 를 요청하라고 알린다.
2. 캐릭터 크기(높이 약 18%, 별하늘 벤치 그림과 같은 비율), 하단 채널명 자리, 위쪽 글귀 자리, 봄이 머리핀, 손가락, 어린이 책가방 없음을 확인한다.
3. 문제없으면 `img/post.jpg` 로 저장 → `preview` → 1440×1800 최종본과 게시글을 준다.
