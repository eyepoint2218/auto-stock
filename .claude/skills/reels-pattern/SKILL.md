# 릴스 패턴 분석 → 원고 작성

## 0. 원칙 (꼭 지킬 것)
- **수치를 지어내지 않는다.** 조회수·팔로워는 사용자가 준 값만 쓴다. 없으면 "미확인"으로 적는다.
- **인스타를 스크래핑하지 않는다.** 로그인·크롤링·비공식 API 금지. 데이터는 사용자가 붙여 넣은 것만 쓴다.
- **남의 대본을 베끼지 않는다.** 구조와 장치만 가져오고 문장은 새로 쓴다.
- **작품 정보(OTT, 장르, 출연, 연도)는 확인된 것만** 쓴다. 확실하지 않으면 원고에 `[확인 필요]`로 표시한다.
- 초안은 항상 `drafts/` 폴더에 `draft: true` 로 만든다. **`queue/` 에는 사용자가 명시적으로 요청할 때만** 옮긴다 (queue 에 들어가면 자동 업로드됨).

## 1. 입력 받기
참고 릴스 데이터는 `references/*.md` (또는 채팅에 붙여 넣은 텍스트). 릴스 1개당 아래 항목을 받는다. 빈 칸은 허용.

```
## R1
- 계정 / 팔로워: @account / 12만
- 링크:
- 조회수: 230만
- 길이: 18초
- 형식: 자막+스틸컷 / 얼굴 출연 / 영상 클립 / 텍스트만
- 0~3초 (화면 글자 + 말):
- 장면별 자막:
- 마지막 CTA:
- 캡션 첫 줄:
```
- 최소 8개, 권장 15~30개. 5개 미만이면 "표본이 너무 적어 패턴이 아니라 우연일 수 있음"을 경고한다.
- 가능하면 **같은 계정의 평범한 릴스 2~3개**도 함께 받아 비교군으로 쓴다 (잘된 것과 안 된 것의 차이가 진짜 패턴).

## 2. 한 편씩 분해 (표)
각 릴스를 아래 열로 정리한다.

| ID | 배수(조회수÷팔로워) | 후킹 유형 | 후킹 문장 | 구성 | 장면 수/길이 | 반전·보상 위치 | CTA |

후킹 유형 분류: 숫자 약속("3편"), 질문/퀴즈, 통념 깨기("다들 ~라는데 사실"), 감정 공감("월요일 밤ㅠ"), 결과 먼저 보여주기, 금지/경고("이거 보면 잠 못 잠"), 정체 숨기기(누군지 맞혀보세요).
구성 분류: 리스트형, 순위형(역순 카운트다운), 스토리형(과거→현재), 비교형(A vs B), 퀴즈형(공개는 마지막).

## 3. 묶어서 패턴 찾기 (핵심)
- 각 특징이 **상위 그룹에서 몇 개 중 몇 개**인지 센다. 비교군이 있으면 비교군 비율과 나란히 적는다.
- "패턴"이라고 부르려면 근거 릴스 ID를 같이 적는다. 예: `숫자 후킹 7/10 (R1,R3,R4…) vs 비교군 1/3`.
- 길이, 장면당 초, 첫 화면 글자 수, 반전 위치(몇 초째)처럼 숫자로 잴 수 있는 것은 중앙값을 낸다.
- 마지막에 **"공식"을 5줄 이내로** 요약한다: 후킹 → 전개 → 보상 → CTA.

## 4. 원고 작성
레포 루트 `CLAUDE.md` 의 **후킹 규칙**을 지키고, post.yml 을 만든 뒤 `python -m screendaily lint` 로 검사한다.
공식마다 원고 3개를 쓴다. 원고 하나에 들어갈 것:
- 0~3초 화면 글자 (15자 이내 권장) + 말풍선
- 장면별 자막 (장면당 3초 기준, config.yml `reel.seconds_per_slide`)
- 마지막 CTA (저장/댓글/팔로우 중 하나만 강하게)
- 캡션 + 해시태그

## 5. post.yml 초안 만들기
- `drafts/<날짜>_<주제>/post.yml` 에 이 레포 형식으로 쓴다 (`README.md` 의 post.yml 항목 표, `examples/` 참고).
- `format: reel`, `draft: true`, `publish_at` 은 임시 날짜.
- 순위형(카운트다운)이면 각 item 에 `year: "3위"` 처럼 적는다. 안 적으면 카드 번호가 01→03 으로 나와 순위와 반대가 된다.
- **카드에 찍히는 글자(title, desc, bubble, outro_question)에는 이모지를 넣지 않는다.** 폰트에 없어서 네모로 깨진다. 이모지는 caption 에만.
- 장면 4~5장 = 약 13~15초 (config 기준 장당 3초, 전환 0.4초).
- 표지 `title` = 3초 후킹 문장, `bubble` = 후킹 말풍선, `items` = 장면, `outro` 질문 = CTA.
- 미리보기: 아래로 카드/영상을 만들어 `drafts/<폴더>/out/` 에서 확인한다.
  ```bash
  python -c "from pathlib import Path; from screendaily.post import load_post, load_config; from screendaily.generate import generate; c=load_config(); print(generate(load_post(Path('drafts/<폴더>'), c), c, force=True))"
  ```

## 6. 결과 보고
`drafts/<폴더>/report.md` 에 2~4단계 결과를 남기고, 채팅에는 공식 5줄 + 원고 목록 + 미리보기 경로만 짧게 알린다.
