# 역사그램 릴스 R01 | 강감찬 20초 A/B 테스트

- 이미지: GPT(텍스트 없는 삽화 4장, 1024×1536) → 영상: 시댄스 이미지→영상 5초×4 = 20초
- 출력: 1080×1920, 30fps, H.264, 600프레임. 자막·워터마크·음악은 편집 단계에서 합성
- TYPE A(검정 배경 글자)와 TYPE B(시댄스 영상)는 자막 문구·시간·위치·음악 동일

| 시간 | 프레임 | 자막 (노란 강조 = [ ]) | 자막 위치 |
|---|---|---|---|
| 0~5초 | 0~149 | 거란 [10만] 대군이 / 무너졌습니다. | 위쪽(세로 32~44%) |
| 5~10초 | 150~299 | 1019년, / 고려의 [귀주]에서. | 위쪽 |
| 10~15초 | 300~449 | 이 전투를 이끈 / 장수는 [누구]일까요? | 위쪽 |
| 15~20초 | 450~599 | [강감찬] / 역사그램 \| HISTORYGRAM | 아래쪽(세로 62~74%) |

정답(이름·얼굴)은 450프레임(15.0초) 이전 노출 금지. 장면 4에 "상상화" 작은 표기.
