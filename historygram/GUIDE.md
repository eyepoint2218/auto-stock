# 역사그램 제작 지침 (@historygram.kr)

역사 속 잘 알려지지 않은 실화와 인물을 5장 + 팔로우 1장 캐러셀로 소개한다.
**역사적 사실은 정확하게, 이야기는 흥미롭게, 이미지는 자연스럽게.** 마지막 장까지 넘겨야 정체를 알 수 있게.

## 매일 한 명 흐름
1. **인물 고르기**: `python -m historygram next` → `people.yml` 맨 위 미완료 인물. 사료로 확인이 어려우면 건너뛰고 이유를 적는다.
2. **사실 확인**: 웹 검색으로 실록·문집·백과(한국민족문화대백과, 국사편찬위원회 등)를 대조. 확인된 것만 쓴다.
3. **회차 만들기**: `python -m historygram new N 이름 slug` → `episodes/epNN_slug/episode.yml` 채우기.
4. **검사**: `python -m historygram check epNN` 경고 0개.
5. **미리보기**: `python -m historygram render epNN` → 1장·6장 완성, 2~5장은 배치 미리보기(`*_layout.png`).
6. **GPT 프롬프트**: `python -m historygram prompt epNN` → 운영자에게 코드 블록 하나로 그대로 전달(한 번에 복붙).
7. **삽화 받기**: 운영자가 GPT 그림 4장을 보내면 장면을 보고 2~5장 순서를 맞춰 `ingest epNN 2장 3장 4장 5장` → `render epNN`.
8. **검수 후 전달**: 한글 오탈자, 인물 일관성, 복식 고증, 글자 잘림·겹침을 화면으로 확인 → `out/preview.png` 보여주고 `out/epNN_slug.zip`(PNG 6장 + caption.txt) 전달.
9. `people.yml` 에 done: true, ep 번호 기록. `status` 갱신.

## 스토리 5장 (+6장)
| 장 | 역할 | 글자 위치 |
|---|---|---|
| 1 | 후킹: 가장 인상적인 발언이나 결말. 검은 배경 + 글자만, 이름 비공개 | 가운데 |
| 2 | 궁금증: 1장이 왜 일어났는지 질문 | 아래 |
| 3 | 숨겨진 사연: 실제 사건 중심 | 아래 |
| 4 | 반전·결정적 행동 | 위 |
| 5 | 인물 공개: 정면 얼굴, 이름 크게, 생몰연도, 한 줄 업적 | 아래 |
| 6 | 공용 팔로우 카드(자동) | - |

- 1~4장에는 이름을 쓰지 않는다. 2~4장 삽화는 뒷모습·손·실루엣으로 정체를 숨긴다.
- 노란색 강조는 장마다 핵심 단어 하나(`[대괄호]`).
- 줄당 글자는 짧게(1장 8자 안팎, 2~4장 10자 안팎). 넘치면 자동으로 줄어들지만 60px 아래면 경고.

## 사실과 연출
- 직접 발언이 확인되지 않은 대사는 재구성 대사로 취급하고, 1장 `note: 재구성 대사` 또는 게시글에 밝힌다.
- 사료와 다른 장면은 해당 장 `note: 재구성 연출`.
- 생전 초상이 없으면 5장 `note: 상상화`. 후대 영정을 생전 초상처럼 말하지 않는다.
- 사료에 없는 대화·사건을 사실처럼 만들지 않는다. `sources`, `staging` 을 반드시 채운다.
- 통설과 사실이 다르면(예: 씨 없는 수박) 그 자체를 후킹으로 쓰되 근거를 게시글에 적는다.

## 게시글
- 첫 문장은 강력한 후킹(인사·자기소개 금지). 배경 → 사건 → 업적과 오늘의 의미 → 독자에게 묻는 문장.
- 과도한 감탄사, AI 특유의 상투 표현, 이모지 금지. 해시태그 최대 5개(#역사그램 포함).
- 채널 소개(`channel_intro.txt`)와 해시태그는 자동으로 붙는다.
