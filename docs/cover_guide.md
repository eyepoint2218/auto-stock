# 혜택알람 표지(01장) 제작 고정 지침

모든 혜택 표지에 똑같이 적용한다. 코드: `screendaily/cards.py` `render_photo_cover`, 검사: `python -m screendaily lint`.
최우선 원칙: **사진은 그대로, 글씨는 크고 굵게, 디자인은 최대한 단순하게.**

## 1. 디자인 콘셉트
- 실제 브랜드 광고나 전문 인스타 정보 채널처럼 자연스럽고 깔끔하게. AI가 만든 듯한 과장된 광고 디자인 금지.
- 사진 80%, 텍스트 20%.
- 원본 사진은 절대 바꾸지 않는다 (색감·구도 보정, 생성형 편집 금지). 새 배경·상품·소품·로고를 만들어 넣지 않는다.

## 2. 규격·배치
- 1080×1350 (4:5). 텍스트는 좌측 하단, 좌측 정렬.
- 주요 상품이나 브랜드 로고를 가리지 않게 `cover_focus` 로 사진 위치를 맞춘다 (사진 자체는 그대로).
- 폰 피드의 작은 썸네일에서도 바로 읽혀야 한다 (검수 시 축소해서 확인).

## 3. 폰트
- 기본 Pretendard Black (900), 보조 Pretendard Bold (700). `assets/fonts/` (SIL OFL).
- 실제 한글 폰트로 조판 (이미지 생성으로 글자를 그리지 않음). 자간 -3% (-2~-4%).

## 4. 색
- 통신사·멤버십·브랜드명(첫 줄): 흰색 #FFFFFF
- 핵심 무료·할인 혜택(둘째·셋째 줄): 노란색 #FFE500
- 명도 차이가 부족하면 텍스트 뒤에만 자연스러운 어두운 그라데이션. 외곽선·입체·그림자 효과 없음.

## 5. 글자 수 (lint 가 검사)
- 첫 줄(멤버십·조건·브랜드) 최대 10자, 브랜드명은 8자 이내 권장
- 핵심 혜택 줄 최대 12자
- 전체 공백 제외 25자 이내, 최대 3줄
- 긴 설명·이용 방법은 표지에 넣지 않는다 (02장 STEP 과 게시글로).

## 6. 크기
- 첫 줄 85~110px, 핵심 혜택 105~140px (가장 크게). 길면 크기를 줄이되 잘리지 않게.

## 7. 금지
붓터치, 빨간 밑줄, 말풍선, 스티커, 장식 아이콘, 과도한 그림자·입체 글자, 네온·글로우·과도한 채도,
불필요한 홍보 문구, AI로 재생성한 브랜드 로고, 원본 사진 색감·구도 변경.

## 8. 예시
```yaml
title: "LG유플러스\n스타벅스\n아메리카노 1+1"   # 흰색 / 노란색 / 노란색
```

## 9. 제작·검수 순서
1. 원본 사진 그대로 사용 (사용자 제공 사진 우선, 사람 얼굴 없는 사진).
2. 확인된 혜택 정보만 문구에 반영.
3. 실제 한글 폰트로 조판 (자동).
4. 오탈자·글자 잘림·정렬 검수, 로고·상품을 글자가 가리지 않는지 확인.
5. 썸네일 크기로 줄여 가독성 확인.
6. 이 디자인을 이후 모든 혜택 표지에 동일하게 적용.
