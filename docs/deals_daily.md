# 혜택알람 매일 자동 피드 (오후 1시 업로드)

매일 아침 예약 작업이 이 문서를 따라 혜택 캐러셀 1개를 만들어 **main 브랜치 `queue/`** 에 넣는다.
업로드는 기존 `인스타 자동 업로드` 워크플로가 13:00 이후 첫 실행(약 13:07)에 한다.
CLAUDE.md 의 혜택알람 규칙을 모두 지킨다. 아래는 그 순서다.

## 1. 혜택 고르기
- 오늘(한국 시간) 기준 **오늘 참여할 수 있고, 오늘 이후에도 최소 하루 이상 남은** 혜택 하나. 오늘 하루짜리면 오늘 날짜가 맞을 때만.
- 무료·할인 혜택 전부 대상: 통신사(T day·KT 달달혜택·U+ 유플투쁠), 카드, 프랜차이즈 이벤트, 쿠폰, 지역 축제·시설 무료 등. 널리 쓸 수 있는 것 우선(전국, 조건 단순).
- **중복 금지**: `queue/`, `published/`, `drafts/` 의 `channel: deals` 게시물과 `docs/deals_log.md` 를 보고 같은 브랜드·같은 혜택은 다시 쓰지 않는다. 최근 3일 안에 쓴 브랜드도 피한다.
- 공식 출처(브랜드·통신사 공지, 보도자료, 언론 기사 2곳 이상)로 **기간·대상·방법을 확인**한 것만. 확인 안 된 조건은 카드에 쓰지 않는다. 확인할 혜택이 없으면 그날은 만들지 않고 로그에 사유만 적는다 (틀린 정보 올리기보다 하루 쉬는 게 낫다).

## 2. 만들기
1. `python -m screendaily new <오늘날짜> 13:00 --deal <브랜드>` 로 `drafts/` 에 생성한 뒤 폴더를 `queue/<YYYY-MM-DD>_1300/` 으로 옮긴다.
2. `post.yml`: `draft: true` 로 시작 (사진 고르기 전 업로드 방지). `publish_at: "<오늘> 13:00"`.
   - `title`: `docs/cover_guide.md` 고정 지침대로. 첫 줄 통신사·멤버십·브랜드(10자 이하), 다음 1~2줄 핵심 혜택(줄당 12자 이하), 최대 3줄 (예 `"LG유플러스\n스타벅스\n아메리카노 1+1"`).
   - steps 3개, 그중 하나에 기간 `MM/DD~MM/DD` 필수.
   - `caption`: 이모지 없이 제목 한 줄 → 기간·대상·혜택·방법 → "세부 조건은 ○○에서 확인하세요." → "팔로우하고 혜택알람 받아보세요". 검색될 키워드(브랜드명·혜택명·무료/할인/쿠폰)를 첫 줄에.
   - `hashtags`: 브랜드·혜택 위주 4개.
   - 맨 위 주석에 확인 날짜와 출처 URL.
3. 표지 사진: 혜택 관련 공식 뉴스룸·기사 페이지를 `cover_url` 로 넣고 `cover_candidates: true`. (이 세션 네트워크는 대부분 이미지 사이트가 막혀 있어 GitHub Actions 미리보기가 받아 온다.)
4. `python -m screendaily lint` 경고 0 확인 → main 에 커밋·푸시.

## 3. 사진 고르고 확정
1. 푸시 후 `chore: 미리보기 생성` 커밋이 올라올 때까지 기다렸다가 pull (20초 간격, 최대 15분).
2. `img/cand_*` 를 직접 보고 고른다: **사람 얼굴 없음**, 혜택과 직접 관련, 다른 할인율·가격 문구가 크게 없는 사진, 가로 600px 이상.
   맞는 게 없으면 다른 기사로 `cover_url` 을 바꿔 다시. 그래도 없으면 `cover_wiki`(사람 없는 대표 사진)로.
3. 고른 파일을 `img/cover.jpg` 로 복사하고 `cover_image: img/cover.jpg`, 필요하면 `cover_focus`, `cover_url`·`cover_candidates` 줄 삭제, 나머지 cand 파일 삭제.
4. `python -m screendaily preview` 로 01·02 장을 직접 보고 글자 겹침·잘림, 글자가 로고·상품을 가리지 않는지(가리면 `cover_focus` 조정), 썸네일 크기 가독성을 확인.
5. `draft: false` 로 바꿔 커밋·푸시 (12:30 전까지). 늦어지면 `publish_at` 을 늦춰도 된다.

## 4. 로그
`docs/deals_log.md` 맨 아래에 한 줄 추가: `| 날짜 | 브랜드 | 혜택 | 폴더 | 출처 |` (쉰 날은 사유).

## 금지
- main 의 다른 게시물·코드 수정 금지 (이 작업은 queue/ 새 폴더와 로그만).
- 사람 얼굴 사진, 확인 안 된 조건, 이모지(카드·게시글), 페이지 번호.
