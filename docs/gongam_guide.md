## 1. 캐릭터 고정 (절대 바꾸지 않는 것)

| | 남자 | 여자 |
|---|---|---|
| 머리 | 짙은 갈색, 삐죽삐죽한 짧은 더벅머리 | 짙은 갈색 어깨 길이 단발, 일자 앞머리 |
| 포인트 | 없음 (머리 모양이 포인트) | **노란 똑딱 머리핀 하나** (보는 사람 기준 오른쪽 위) |
| 기본 옷 | **빨간** 니트 + 연청 청바지 | **노란** 가디건 + 흰 블라우스 + 베이지 긴 치마 |
| 신발 | 흰 운동화 | 흰 운동화 |
| 키 | 여자보다 머리 반 개 정도 큼 | 남자보다 조금 작음 |

공통: **20대 후반 어른**, 귀여운 SD 비율(3등신), 동그란 얼굴, **세로로 긴 까만 타원 눈**(흰 하이라이트 점), 볼에 **빨간 빗금 세 줄 볼터치**,
작은 입, 살구색 피부, 깔끔한 짙은 갈색 외곽선, 납작한 2D 셀 채색.

### 옷은 계절·장면에 따라 바꿔도 되지만 색 규칙은 지킨다
- 남자 = **빨강 상의**, 여자 = **노랑 상의** (코트, 패딩, 니트, 셔츠, 잠옷 모두)
- 여자 머리핀, 남자 더벅머리, 볼 빗금, 눈 모양은 **어떤 장면에서도 그대로**
- 어른 소품만: 커피잔, 휴대폰, 토트백·크로스백, 장바구니, 우산, 자전거. **책가방·교복·학교 장소는 쓰지 않는다**

### 그림체 규칙
- 캐릭터는 **2D 만화 그대로**, 배경만 **실사 사진**처럼 (보정된 감성 사진, 얕은 심도)
- 실사 배경의 빛(노을, 가로등, 비)이 캐릭터에도 살짝 비치게, 발밑 그림자·물 반사
- 캐릭터를 3D·사실적으로 바꾸지 않는다 (가장 흔한 실패)
- 스킨십은 손잡기·어깨 기대기·포옹·우산 같이 쓰기·이마 맞대기 정도로 담백하게

## 2. GPT 프롬프트 틀 (매번 그대로 복사, `[장면]`과 `[글귀]`만 바꾼다)

첨부: ① `couple_character.png` (없으면 `siblings_character.png`) ② `siblings_style_ref.jpg`

```

- 폰트: 흰색의 단정한 고딕체(본고딕 Medium 느낌), 중간 굵기, 외곽선·장식 없이 아주 옅은 그림자만
```

### 글귀 기준값 (기준 이미지 `siblings_style_ref.jpg` 1086×1448 실측)
| 항목 | 값 |
|---|---|
| 글자 높이 | 29px (세로의 2.0%) |
| 첫 줄 위치 | 위에서 275px (19%) |
| 줄 간격 | 40px (글자 높이의 1.4배) |
| 한 줄 폭 | 8자 줄 기준 230~260px (가로의 21~24%). 글자 수가 많으면 폭만 늘고 글자 크기는 그대로 |
| 정렬·색 | 가운데, 흰색(#F8F8F8), 그림자 거의 없음 |

### 표정은 시트에서 고른다
기본, 웃음(눈웃음), 활짝 웃음, 윙크, 생각(고민), 놀람, 설렘, 졸림.

### 장면 쓰는 요령
- 두 사람의 **다정한 관계**가 보이게: 우산 같이 쓰기, 손잡고 걷기, 어깨 기대기, 목도리 둘러 주기, 커피 건네기, 업어 주기
- 실사 배경은 **한국 일상 데이트·생활 장소**: 동네 카페 창가, 한강, 골목길, 버스정류장, 편의점 앞, 둘이 사는 듯한 작은 거실·주방, 공원 벤치, 퇴근길 지하철역 출구
- 시간대·날씨로 감정을 만든다: 비=위로, 노을=하루 끝, 첫눈=설렘, 새벽 파란빛=불안, 봄볕=응원
- 실존 인물·브랜드 간판·로고는 넣지 않는다

## 3. 캐릭터가 바뀌지 않게 하는 방법 (중요)

1. **ChatGPT 프로젝트 하나**를 만들어 이 연재 전용으로 쓴다. 프로젝트 지침에 위 `[캐릭터 고정]`을 붙여 두고,
   파일에 `couple_character.png`, `siblings_style_ref.jpg` 를 올려 둔다.
2. 새 그림마다 **두 이미지를 다시 첨부**한다 (대화가 길어지면 캐릭터가 흐려진다). 한 대화에서 5장 넘게 만들지 않는다.
3. 커플 완성본이 쌓이면 가장 시트와 닮은 것 1장을 세 번째 기준으로 함께 첨부한다.
   첫 커플 완성본이 나오면 그것을 `siblings_style_ref.jpg` 대신 합성 스타일 기준으로 써도 된다 (글귀 크기가 같을 때만).
4. 얼굴이 바뀌면 처음부터 다시 만들지 말고 이렇게 고친다:
   > 첫 번째 첨부 시트와 같은 캐릭터로 다시. 남자 더벅머리, 여자 일자 앞머리와 노란 머리핀, 세로로 긴 까만 눈, 빨간 빗금 볼터치를 똑같이. 배경과 글귀는 그대로.
5. 아이처럼 나오면:
   > 두 사람 모두 20대 후반 어른으로. 얼굴과 그림체는 그대로 두고 어른 체형·어른 옷차림으로, 책가방은 빼줘.
6. 글자가 틀리면 그림은 두고 글만 고친다:
   > 그림은 그대로 두고 위쪽 글만 정확히 "(첫째 줄) / (둘째 줄)" 로 고쳐줘.
7. 글자가 크거나 굵게 나오면:
   > 그림은 그대로 두고 글귀만 두 번째 첨부 이미지와 같은 크기로 작게. 글자 높이는 화면 세로의 2%, 중간 굵기 흰색 고딕체, 가운데 정렬, 위에서 19% 지점.

### 올리기 전 확인 (하나라도 틀리면 다시 생성)
- [ ] 두 사람이 **어른 커플**로 보임 (책가방·교복·아이 옷 없음)
- [ ] 남자 빨간 상의, 여자 노란 상의
- [ ] 여자 노란 머리핀 위치 (보는 사람 기준 오른쪽 위)
- [ ] 눈이 세로 타원, 볼에 빗금 세 줄
- [ ] 캐릭터가 2D 그대로 (3D·실사 얼굴 아님), 손가락·다리 개수 정상
- [ ] 글귀 맞춤법·띄어쓰기 정확, 다른 글자 없음
- [ ] 글귀 폰트·크기·위치가 기준 이미지와 같음 (`textcheck` 통과)
- [ ] 글귀와 얼굴이 맨 위·아래 8% 밖

## 4. 글 규칙

### 그림 속 글귀: 감성 문구 (가장 중요)
- **문구는 `data/gongam_topics.md` 의 '감성·위로 문구 40선'에서만 고른다. 원문 그대로** (글자·띄어쓰기·문장부호를 바꾸지 않음). 새 문구는 운영자가 요청할 때만 만들고, 만들면 40선과 같은 결로 쓴다.
- **두 줄**로 나눈다 (긴 문장만 3줄). 줄당 12자 이하(공백 제외). 뜻이 끊기는 곳에서 나누고 원문에 없는 부호를 더하지 않는다. ("오늘 같은 날엔 / 따뜻한 한 잔이면 충분해.")
- 첫 줄은 마음이 머무는 순간, 둘째 줄은 다정한 한마디. 낮고 다정한 반말 ("~해도 괜찮아", "~있을게", "~거야")
- 웃음·말장난·유행어·숫자 개그는 쓰지 않는다. 조용히 오래 남는 문장.
- 쉬운 단어로: 마음, 하루, 곁, 천천히, 괜찮아, 따뜻한, 그리운, 애썼어
- 이모지·물결·느낌표 금지, 인사·자기소개 금지, 설교·명령조 금지 ("~해라", "~해야 한다")

### 요일별 결 (모두 감성, 같은 결을 연달아 쓰지 않는다)
| 요일 | 결 | 예 |
|---|---|---|
| 월 | 위로·쉼 (버거운 마음을 다독임) | "오늘도 참 애썼어. / 그걸로 충분해." |
| 수 | 일상의 작은 위안 (비·햇살·차 한 잔) | "오늘 같은 날엔 / 따뜻한 한 잔이면 충분해." |
| 금 | 곁에 있는 사람 (연인·고마움·함께) | "말하지 않아도, / 곁에 있을게." |

### 게시글(caption)
```
(글귀 두 줄 그대로)

(상황을 풀어 쓴 2~3줄, 담백하게)

(CTA 하나) 함께 보고 싶은 사람에게 보내주세요.   ← 공감툰은 '공유'가 가장 강한 CTA
```
- 이모지 없이. 끝에 채널 소개·검색 키워드·해시태그는 자동으로 붙는다.
- `hashtags` 는 그 장면 키워드 1~2개만 (기본 해시태그가 나머지를 채움, 최대 5개).
- CTA는 하나만: 월 = 저장("지칠 때 꺼내 보게 저장해 두세요"), 수 = 댓글("요즘 당신의 작은 위안은 무엇인가요?"), 금 = 공유("함께 보고 싶은 사람에게 보내주세요").
