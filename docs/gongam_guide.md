## 1. 캐릭터 고정 (절대 바꾸지 않는 것)

| | 오빠 | 동생 |
|---|---|---|
| 머리 | 짙은 갈색, 삐죽삐죽한 짧은 더벅머리 | 짙은 갈색 단발 보브, 일자 앞머리 |
| 포인트 | 없음 (머리 모양이 포인트) | **노란 똑딱 머리핀 하나** (보는 사람 기준 오른쪽 위) |
| 기본 옷 | **빨간** 반팔 티셔츠 + **노란** 반바지 | **노란** 원피스 + 흰 둥근 카라 |
| 신발 | 흰 운동화 | 흰 운동화 |
| 키 | 동생보다 머리 반 개 정도 큼 | 오빠보다 조금 작음 |

공통: 2.5~3등신, 동그란 얼굴, **세로로 긴 까만 타원 눈**(흰 하이라이트 점), 볼에 **빨간 빗금 세 줄 볼터치**, 작은 입,
살구색 피부, 깔끔한 짙은 갈색·검은 외곽선, 납작한 2D 셀 채색.

### 옷은 계절에 따라 바꿔도 되지만 색 규칙은 지킨다
- 오빠 = **빨강 상의**, 동생 = **노랑 상의** (우비, 패딩, 니트, 잠옷 모두)
- 동생 머리핀, 오빠 더벅머리, 볼 빗금, 눈 모양은 **어떤 장면에서도 그대로**
- 소품(가방·우산 등)은 자유. 예: 오빠 노란 가방, 동생 분홍 가방

### 그림체 규칙
- 캐릭터는 **2D 만화 그대로**, 배경만 **실사 사진**처럼 (보정된 감성 사진, 얕은 심도)
- 실사 배경의 빛(노을, 가로등, 비)이 캐릭터에도 살짝 비치게, 발밑 그림자·물 반사
- 캐릭터를 3D·사실적으로 바꾸지 않는다 (가장 흔한 실패)

## 2. GPT 프롬프트 틀 (매번 그대로 복사, `[장면]`과 `[글귀]`만 바꾼다)

```
첨부한 캐릭터 시트의 오빠와 동생을 똑같은 얼굴, 머리, 눈, 볼터치, 그림체로 그려줘.
두 번째 첨부 이미지처럼, 캐릭터는 2D 만화 그대로 두고 배경만 실사 사진으로 합성한 한 장이야.

[캐릭터 고정]
- 오빠: 짙은 갈색 삐죽삐죽 짧은 더벅머리, 세로로 긴 까만 타원 눈, 볼에 빨간 빗금 세 줄, 빨간 상의 + 노란 반바지, 흰 운동화
- 동생: 짙은 갈색 단발 보브 + 일자 앞머리, 노란 머리핀 하나(보는 사람 기준 오른쪽 위), 같은 눈과 볼터치, 노란 원피스 + 흰 둥근 카라, 흰 운동화
- 2.5~3등신, 동그란 얼굴, 깔끔한 갈색 외곽선, 납작한 2D 셀 채색. 오빠가 동생보다 조금 큼
- 옷을 바꿀 때도 오빠는 빨간 상의, 동생은 노란 상의

[장면]
(장소·계절·시간대·날씨·빛을 실사 사진처럼 2문장, 두 캐릭터의 자세·표정·소품 2문장)

[글귀]
이미지 위쪽 가운데(위에서 15~25% 지점)에 아래 글을 정확히 그대로, 두 줄로 써줘.
"(첫째 줄)"
"(둘째 줄)"
- 흰색 깔끔한 고딕체, 중간 굵기, 아주 옅은 그림자
- 글자 크기는 화면 가로의 4~5% 정도, 맞춤법·띄어쓰기 그대로, 다른 글자·숫자·간판·워터마크는 넣지 마

[규칙]
- 세로 3:4 비율
- 캐릭터는 화면 가운데 아래쪽 1/3 지점에 전신으로, 두 캐릭터가 서로 가리지 않게
- 글귀 뒤 배경은 하늘·나무처럼 단순하고 어두워서 흰 글씨가 잘 읽히게
- 화면 맨 위·맨 아래 8%에는 글자와 얼굴을 두지 마 (인스타 4:5로 잘림)
```

### 표정은 시트의 8개 중에서 고른다
기본(입벌림/웃음), 웃음(행복·눈웃음), 활짝 웃음, 윙크, 생각(고민), 놀람, 신남, 잠(졸림).
울먹·서운함이 필요하면 "눈썹을 살짝 내린 서운한 표정, 눈물 한 방울" 처럼 **시트 그림체 그대로** 라고 덧붙인다.

### 장면 쓰는 요령
- 이야기의 **관계**가 보이게: 우산 씌워주기, 업어주기, 간식 나누기, 등 토닥이기, 나란히 앉기
- 실사 배경은 **한국 일상 장소**: 아파트 놀이터, 동네 편의점 앞, 버스정류장, 한강, 골목 계단, 학교 운동장, 지하철역 출구
- 시간대·날씨로 감정을 만든다: 비=위로, 노을=하루 끝, 첫눈=설렘, 새벽 파란빛=불안, 봄볕=응원
- 실존 인물·브랜드 간판·로고는 넣지 않는다

## 3. 캐릭터가 바뀌지 않게 하는 방법 (중요)

1. **ChatGPT 프로젝트 하나**를 만들어 이 연재 전용으로 쓴다. 프로젝트 지침에 위 `[캐릭터 고정]`을 붙여 두고,
   파일에 `siblings_character.png`, `siblings_style_ref.jpg` 를 올려 둔다.
2. 새 그림마다 **두 이미지를 다시 첨부**한다 (대화가 길어지면 캐릭터가 흐려진다). 한 대화에서 5장 넘게 만들지 않는다.
3. 마음에 든 완성본이 쌓이면 그중 가장 시트와 닮은 것 1장을 세 번째 기준으로 함께 첨부한다.
4. 얼굴이 바뀌면 처음부터 다시 만들지 말고 이렇게 고친다:
   > 첫 번째 첨부 시트와 같은 캐릭터로 다시. 오빠 더벅머리, 동생 일자 앞머리와 노란 머리핀, 세로로 긴 까만 눈, 빨간 빗금 볼터치를 똑같이. 배경과 글귀는 그대로.
5. 글자가 틀리면 그림은 두고 글만 고친다:
   > 그림은 그대로 두고 위쪽 글만 정확히 "(첫째 줄) / (둘째 줄)" 로 고쳐줘.

### 올리기 전 확인 (하나라도 틀리면 다시 생성)
- [ ] 오빠 빨간 상의, 동생 노란 상의
- [ ] 동생 노란 머리핀 위치 (보는 사람 기준 오른쪽 위)
- [ ] 눈이 세로 타원, 볼에 빗금 세 줄
- [ ] 캐릭터가 2D 그대로 (3D·실사 얼굴 아님), 손가락·다리 개수 정상
- [ ] 글귀 맞춤법·띄어쓰기 정확, 다른 글자 없음
- [ ] 글귀와 얼굴이 맨 위·아래 8% 밖

## 4. 글 규칙

### 그림 속 글귀 (가장 중요)
- **두 줄, 줄당 15자 이하** (공백 제외), 반말의 다정한 말투 ("~해도 괜찮아", "~했구나")
- 앞줄은 **상황**, 뒷줄은 **위로·반전** ("마음이 아플 때는, / 잠시 멈춰도 괜찮아.")
- 구체적으로: "힘들 때" 보다 "월요일 아침", "답장 안 오는 밤", "혼자 밥 먹는 날"
- 이모지·해시태그·물결 남발 금지, 문장부호는 쉼표·마침표 정도만
- 인사·자기소개 금지, 설교·명령조 금지 ("~해라", "~해야 한다")

### 요일별 결 (같은 결을 연달아 쓰지 않는다)
| 요일 | 결 | 예 |
|---|---|---|
| 월 | 위로·응원 (한 주의 시작이 버거운 마음) | "월요일이 무거운 건 / 주말이 좋았다는 뜻이야." |
| 수 | 일상 공감·웃음 (그거 나야) | "5분만 더 누워 있자 했는데 / 30분이 지났어." |
| 금 | 관계·고마움 (곁에 있는 사람) | "말 안 해도 알아주는 사람, / 그거면 충분해." |

### 게시글(caption)
```
(글귀 두 줄 그대로)

(상황을 풀어 쓴 2~3줄, 담백하게)

(CTA 하나) 생각나는 사람에게 보내주세요.   ← 공감툰은 '공유'가 가장 강한 CTA
```
- 이모지 없이. 끝에 채널 소개·검색 키워드·해시태그는 자동으로 붙는다.
- `hashtags` 는 그 장면 키워드 1~2개만 (기본 해시태그가 나머지를 채움, 최대 5개).
- CTA는 하나만: 월 = 저장("지칠 때 꺼내 보게 저장해 두세요"), 수 = 댓글("나만 그래요? 댓글로 알려주세요"), 금 = 공유.
