# 온이봄이 만능 프롬프트 (사진 + 분위기 → 그림)

사진 한 장과 분위기 한두 줄만 바꾸면 되는 고정 프롬프트. 장면·자세·표정은 GPT가 분위기에 맞춰 정한다.
글자 없는 그림만 받는다. 글귀와 채널명은 프로그램이 넣는다 (`docs/gongam_guide.md`).

## 첨부 (순서 중요)
1. `assets/brand/siblings_style_ref.jpg`: 우산 그림 (얼굴·선 굵기·채색·합성 방식 기준)
2. 계절 시트 하나
   - 겨울(12~2월 실외): `assets/brand/siblings_winter.png`
   - 크리스마스(12/23·12/25): `assets/brand/siblings_christmas.png`
   - 그 밖(실내, 봄·가을): `assets/brand/siblings_character.png`
3. 배경 참고 사진 (원하는 장소·빛·계절이 담긴 사진)

## 바꾸는 곳
맨 아래 `[분위기]` 한두 줄만 쓴다. 예:
- 참아 왔던 마음이 터지는 밤, 곁에서 조용히 토닥여 주는 위로
- 첫눈 오는 저녁의 설렘, 둘이 같이 웃는 따뜻함
- 아무 일 없는 일요일 오후의 느긋함

## 프롬프트 (통째로 복사)

```
첨부한 세 장으로 인스타 감성 공감툰 그림 한 장을 만들어줘. 글자는 하나도 넣지 마.

[첨부 설명]
- 첫 번째 이미지(비 오는 공원): 오빠 '온이'와 동생 '봄이'의 얼굴·머리·눈·볼터치·선 굵기·채색, 그리고 2D 캐릭터를 실사 배경에 합성하는 방식의 기준. 이 이미지의 글귀·장소·옷·가방은 따라 하지 마
- 두 번째 이미지(캐릭터 시트): 이번 그림의 옷·색·로고·각도·표정 기준. 옷은 이 시트에 그려진 차림 그대로
- 세 번째 이미지(사진): 배경 참고. 이 사진의 장소·구도·빛·날씨·계절감을 살려서 실사 사진 같은 배경을 만들어. 사진 속 사람·간판 글자·로고·번호판은 모두 빼

[캐릭터 고정]
- 온이(오빠): 따뜻한 갈색 삐죽삐죽 짧은 더벅머리, 세로로 긴 까만 타원 눈, 볼에 빨간 빗금 세 줄
- 봄이(동생): 따뜻한 갈색 단발 보브 + 일자 앞머리, 노란 두 줄 똑딱핀 하나(보는 사람 기준 오른쪽 위, 항상 보이게), 같은 눈과 볼터치
- 2.5~3등신, 동그란 얼굴, 살구색 피부. 온이가 봄이보다 조금 큼
- 선: 첫 번째 이미지와 같은 굵기. 거의 검정에 가까운 짙은 갈색 외곽선, 바깥 윤곽은 굵고 일정하게, 안쪽 선은 조금 가늘게, 매끈한 디지털 펜 느낌
- 채색: 납작한 셀 채색, 옷 주름에만 아주 옅은 그림자. 그라데이션·3D 입체감 없음
- 캐릭터는 2D 만화 그대로, 배경만 실사 사진
- 옷: 두 번째 시트의 차림 그대로 (다른 옷 금지). 옷 로고는 시트에 있는 'ONIBOMI'만, 철자 그대로. 실제 브랜드 로고 금지
- 가방: 노란·분홍 어린이 책가방 금지. 장면에 꼭 필요할 때만 심플한 백팩(온이 짙은 남색, 봄이 크림색, 무늬·글자 없음)

[장면 만드는 법]
- 아래 [분위기]에 맞게 두 사람의 자세·표정·소품·관계(곁에 앉기, 토닥이기, 우산 씌워주기, 손잡기, 나눠 먹기 등)를 네가 정해
- 표정은 두 번째 시트의 표정에서 골라. 울거나 서운한 표정이 필요하면 시트 그림체 그대로 눈썹을 내리고 눈물 한두 줄기
- 분위기에 맞게 시간대·빛·날씨를 조절해 (위로=비·밤 가로등, 설렘=첫눈·노을, 쉼=오후 햇살, 고마움=따뜻한 실내 조명)

[구도 규칙]
- 세로 3:4 비율, 가능한 가장 높은 해상도
- 이미지 안에 글자·숫자·문장·채널명·워터마크를 하나도 넣지 마. 옷의 'ONIBOMI' 로고만 예외
- 캐릭터 크기 (꼭 지켜): 두 사람이 차지하는 높이는 화면 세로의 30% 이하. 머리 꼭대기는 위에서 58~60% 지점, 발끝은 위에서 88% 지점보다 위. 앉은 장면도 똑같이
- 위치: 화면 가운데 아래쪽, 두 사람이 서로 가리지 않게. 나머지는 실사 배경이 넓게 보이게
- 화면 위쪽 15~36%는 글귀가 들어갈 자리: 하늘·벽·먼 배경처럼 차분하고 조금 어두운 톤. 비우거나 잘라내지 말고 장면을 자연스럽게 이어서 그려 (밝은 조명·햇빛·하얀 눈은 이 영역에 두지 마)
- 맨 아래 89~94% 가운데는 채널명 자리: 바닥처럼 단순하게
- 원근감: 실제 카메라로 찍은 것처럼 소실점이 있는 깊은 공간. 앞쪽 흐린 소품 살짝, 가운데 캐릭터, 뒤로 갈수록 작고 흐려지는 배경. 캐릭터 눈높이 카메라, 35mm 렌즈, 얕은 심도
- 캐릭터 크기는 배경 사물과 실제 비율이 맞게, 발밑에 바닥 원근에 맞는 그림자
- 한강·강변·한강 다리 배경은 쓰지 마 (사진이 강변이면 비슷한 분위기의 다른 동네 장소로)
- 실존 인물·브랜드 간판·로고는 넣지 마

[분위기]
(여기에 한두 줄)
```

## 받은 뒤
그림과 글귀(문장)를 함께 보내면, 글귀를 원문 그대로 넣어 1440×1800 최종본과 게시글을 만든다.
확인: 글자 없음 · 캐릭터 크기(머리 꼭대기 위에서 58% 아래) · 머리핀 · ONIBOMI 철자 · 어린이 책가방 없음 · 위쪽 글귀 자리가 차분한지
