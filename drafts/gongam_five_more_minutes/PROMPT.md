# 수 11/25 · 일상 공감: 겨울 아침 "5분만 더"

글귀: "5분만 더 누웠는데 / 30분이 지났어."
대안: "이불 밖은 위험해, / 오늘도 지각이야." · "알람은 다섯 개, / 일어난 건 한 번."

첨부: assets/brand/siblings_character.png, assets/brand/siblings_style_ref.jpg

```
첨부한 캐릭터 시트의 오빠와 동생을 똑같은 얼굴, 머리, 눈, 볼터치, 그림체로 그려줘.
두 번째 첨부 이미지처럼, 캐릭터는 2D 만화 그대로 두고 배경만 실사 사진으로 합성한 한 장이야.

[캐릭터 고정]
- 오빠: 짙은 갈색 삐죽삐죽 짧은 더벅머리, 세로로 긴 까만 타원 눈, 볼에 빨간 빗금 세 줄, 빨간 상의 + 노란 반바지, 흰 운동화
- 동생: 짙은 갈색 단발 보브 + 일자 앞머리, 노란 머리핀 하나(보는 사람 기준 오른쪽 위), 같은 눈과 볼터치, 노란 원피스 + 흰 둥근 카라, 흰 운동화
- 2.5~3등신, 동그란 얼굴, 깔끔한 갈색 외곽선, 납작한 2D 셀 채색. 오빠가 동생보다 조금 큼
- 옷을 바꿀 때도 오빠는 빨간 상의, 동생은 노란 상의

[장면]
겨울 아침, 실사 사진 같은 아늑한 한국 아파트 침실. 창문 커튼 틈으로 차가운 하얀 아침 햇살이 들어오고, 창밖은 서리 낀 유리, 머리맡 협탁 위 휴대폰 화면이 밝게 켜져 있어.
두툼한 흰 이불 속에 오빠(빨간 잠옷 상의)와 동생(노란 잠옷 상의)이 나란히 누워 얼굴만 내밀고, 둘 다 시트의 '잠(졸림)' 표정으로 눈을 감고 있어. 동생 머리핀은 그대로 꽂혀 있어.

[글귀]
이미지 위쪽 가운데(위에서 15~25% 지점)에 아래 글을 정확히 그대로, 두 줄로 써줘.
"5분만 더 누웠는데"
"30분이 지났어."
- 흰색 깔끔한 고딕체, 중간 굵기, 아주 옅은 그림자
- 글자 크기는 화면 가로의 4~5% 정도, 맞춤법·띄어쓰기 그대로, 다른 글자·숫자·간판·워터마크는 넣지 마

[규칙]
- 세로 3:4 비율
- 캐릭터는 화면 가운데 아래쪽 1/3 지점에, 두 캐릭터가 서로 가리지 않게
- 글귀 뒤 배경은 벽·커튼처럼 단순하고 차분해서 흰 글씨가 잘 읽히게
- 화면 맨 위·맨 아래 8%에는 글자와 얼굴을 두지 마 (인스타 4:5로 잘림)
- 휴대폰 화면에 숫자나 글자를 넣지 마
```
