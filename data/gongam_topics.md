# 오누이 공감툰 주제 창고 (감성 문구)

`docs/gongam_guide.md` 4장 규칙 기준: 두 줄, 줄당 5~10자(공백 제외), 첫 줄은 쉼표, 둘째 줄은 마침표로 끝.
쓴 주제는 `[x]` 로 표시하고 게시 날짜를 적는다.

## 월: 위로·쉼
- [x] 비 오는 공원, 서로 우산 쓰고 마주 봄 · "마음이 아플 때는, / 잠시 멈춰도 괜찮아." (11/23 초안)
- [ ] 월요일 아침 버스정류장, 오빠가 동생 가방을 들어 줌 · "무거운 하루라도, / 같이 들면 가벼워."
- [ ] 새벽 파란빛 아파트 베란다, 담요 하나를 같이 덮고 앉음 · "잠 못 드는 밤에도, / 아침은 꼭 와."
- [ ] 첫눈 오는 골목 계단, 넘어진 동생에게 오빠가 손 내밂 · "넘어져도 괜찮아, / 내가 여기 있을게."
- [ ] 노을 지는 한강 둔치, 나란히 앉아 강 바라봄 · "오늘 하루도, / 참 애썼어."
- [ ] 해 질 녘 학교 운동장, 오빠가 동생 머리 쓰다듬음 · "결과보다 소중한 건, / 애쓴 너의 시간이야."
- [ ] 겨울밤 편의점 앞, 김 나는 호빵을 반씩 나눔 · "추운 날일수록, / 마음은 더 따뜻하게."
- [ ] 봄볕 벚꽃길, 천천히 걷는 두 사람 · "천천히 피어도, / 꽃은 꽃이야."

## 수: 일상의 작은 위안
- [x] 겨울 아침 침실, 창가 햇살 아래 이불 속 두 사람 · "따뜻한 이불 속에서, / 조금만 더 머물자." (11/25 초안)
- [ ] 김 서린 동네 분식집 창가, 떡볶이 앞에 나란히 · "별것 아닌 하루가, / 나중엔 그리워질 거야."
- [ ] 비 갠 골목, 물웅덩이에 비친 하늘을 들여다봄 · "비가 그친 뒤에야, / 하늘이 보이더라."
- [ ] 노을 진 놀이터 그네, 천천히 흔들림 · "높이 오르지 않아도, / 바람은 시원해."
- [ ] 김 서린 창문에 손가락으로 그림 그리기 · "흐린 날에도, / 그릴 수 있는 게 있어."
- [ ] 가로등 켜진 저녁 골목, 손잡고 집으로 · "길을 잃어도 괜찮아, / 돌아오는 길은 있어."
- [ ] 여름밤 아파트 평상, 수박 한 조각씩 · "아무 일 없는 하루가, / 제일 좋은 날이었어."
- [ ] 오후 햇살 드는 빈 교실 창가 · "느리게 가는 오후도, / 언젠가 그리울 거야."

## 금: 곁에 있는 사람
- [ ] 저녁 골목, 오빠가 졸린 동생을 업고 걸어감 · "말하지 않아도, / 알아주는 사람이 있어."
- [ ] 거실 생일 케이크 촛불, 동생이 작은 선물을 내밂 · "네가 태어난 날은, / 나에게도 선물이야."
- [ ] 해 질 녘 놀이터, 길게 늘어진 그림자 두 개 · "같이 걷는 길은, / 멀어도 짧아."
- [ ] 비 오는 버스정류장, 오빠 우산이 동생 쪽으로 기울어짐 · "내 어깨는 젖어도, / 네가 웃으면 돼."
- [ ] 크리스마스 트리 불빛 앞, 서로 마주 보며 웃음 · "올해도 곁에 있어 줘서, / 정말 고마워."
- [ ] 캠핑장 모닥불, 구운 마시멜로를 나눠 먹음 · "좋은 건 나누면, / 두 배가 되더라."
- [ ] 겨울 바닷가 모래사장, 나란히 찍힌 발자국 · "어디로 가든, / 같이 가면 돼."
- [ ] 주말 아침 식탁, 오빠가 만든 서툰 계란말이 · "서툴러도 괜찮아, / 마음은 다 보였어."
